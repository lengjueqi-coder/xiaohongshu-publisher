# 自动发布与提醒

一个直接放图片的子文件夹代表一组待发布素材。根目录支持按年份/月递归扫描；`已发布` 不参与扫描。平铺的一个大图片目录不会自动按拍摄主题拆组。

## 首次配置

1. 在工作台确认目标 Chrome 用户资料和小红书账号；查看已有账号画像，纠正定位、受众、语气和业务事实。
2. 在账号画像设置常用发布时间段。自动发布页选择素材根目录、每天条数、原图/拼图、可见范围、水印等规则。建议从每天 1 条开始。
3. 要按画像生成内容，选择 AI 文案。本地模板是摄影通用文案，不会理解图片或画像。AI 失败时建议暂停；模板回退应明确选择。
4. 每组可放 UTF-8 的 `发布说明.txt`（最大 24KB），填写真实拍摄事实和希望表达的角度。AI 路径会读取说明及该账号近期文案。当前没有图片视觉理解功能。
5. 保存规则、绑定当前账号，先制作一批待审核草稿。检查图片、文字、账号、话题、原创、可见范围和时间。启用全自动计划后，符合已保存规则的新任务会自动提交。

已保存的计划是独立设置快照。留空的合集、地点和话题模板不会自动改成工作台默认值。“保存规则并同步到未提交任务”仅更新自动任务的发布设置，不更新图片、正文和排期。

## 时间和异常

自动计划选位至少留出 90 分钟；提交前及上传后再次检查至少 1 小时提前量。大量任务排队仍可能耗尽提前量，此时停止并要求重新排期，不自动改成马上发布。不同提交间隔为 8–20 分钟，生产新任务不会打断这个间隔。

全自动生成遇到近期相同标题或高度相似正文会停止；可以补充发布说明或更换文案角度。审核草稿允许人工修改后决定。相似度检查不能替代事实核对与文案审美判断。

登录失效、验证码、页面不匹配、图片缺失、状态不明会暂停。状态不明必须先去平台核对，不能盲目再发。已填入不等于已提交，已接收不等于已发布；队列任务会继续查管理页，确认发布后才尝试移动原素材文件夹到 `已发布/`。手动直接提交的记录仍需在工作台主动核验。

## 提醒和后台运行

自动发布页可选择系统提示音、中文语音或自定义录音，设置播放次数与重复间隔；先试听验证系统音量及权限。“已处理”只停止该提醒，恢复计划需另行启用。

后台运行可设置登录后启动和防闲置休眠。关机、手动睡眠、合盖、断网、拔出素材或软件所在硬盘都会影响运行；提醒目前只到这台 Mac，不会自动发到手机。

更新代码后需重启服务；运行中的旧进程不会自动加载文件修改。建议暂停任务、确认没有待核对提交后再重启。遇到验证码、安全验证或平台限制，先人工处理，不做绕过。

## 开发验证

在应用目录使用安装好的虚拟环境：

```sh
.venv/bin/python -m unittest discover -s app -p '*tests.py'
node --test app/account-workspace-tests.cjs
```

安装包没有 `tools/package_release.py` 时，明确跳过两项开发用发布打包测试，其余更新测试仍运行。本地测试通过不能替代真实平台发布验收。
