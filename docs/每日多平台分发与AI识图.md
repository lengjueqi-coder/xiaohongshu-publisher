# 每日多平台分发与可选 AI 识图

本机实现更新于 2026-11-19。三平台图文和视频共用素材、标题、正文、话题；各平台的隐私、声明、合集、位置和定时设置分别保存。正式运营计划默认暂停。

## 一次填写，分发三平台

在左上角切换抖音或视频号，连接对应的官方页面，选择图片或一个视频，填写共用文案和话题，分别确认各平台设置，勾选目标平台后点击发布。小红书图文页底部也有“同步抖音 / 同步视频号”选项；小红书视频入口会进入支持三平台的共用视频工作区。

一次确认后，后台先上传并核对所有目标平台，再依次提交。各平台无法保证在同一秒上线，也无法保证一起成功；已提交的平台不会因为另一个平台失败而重复提交。刷新工作台后，顶部“分发记录”仍能查看状态。

官方发布窗口过窄时，软件会尝试加宽当前 Chrome 窗口；无法调整或按钮被遮挡时会停止并提示处理，不会继续点击屏幕外的位置。视频号会优先复用账号已核实的空发布页或作品管理页；已有内容的草稿保留，登录过期仍需本人扫码。

提交前失败可以修正后继续；已经点击但结果不明时，需要先读取官方作品结果或人工核实。“继续尚未提交的平台”会跳过已提交和结果不明的平台。“已核实官方未接收”只应在官方管理页仔细确认后使用。

平台登录和短信、扫码等本人验证由账号本人在 Chrome 完成，不需要把密码或验证码交给软件开发者。软件不会绕过验证，也不承诺永远不会被识别为自动化。

## 每天从文件夹读取 1～2 组

进入“自动发布”，使用顶部“多平台 · 每日文件夹分发”。下方“原小红书专属计划”保留原拼图、文案库和审核流程；同一账号不能同时用两个计划发布小红书。

1. 选择实际待发布素材根目录。图片按文件名和“每组最多图片”分组，剩余图片保留到下一组；每个视频独立成组。不混合图文和视频。
2. 选择每日 1 组或 2 组，填写对应的北京时间，例如 `12:00, 21:00`，勾选平台。
3. 选择文案来源：根据账号画像生成 AI 文案，或读取素材所在文件夹的 `发布文案.json`。不使用 AI 时不需要视觉模型密钥。
4. 如需结合画面写文案，勾选“AI 识图辅助写文案”，并在设置中配置可用的视觉模型。
5. 在各发布页设置好隐私、声明、位置等，再点“保存规则及当前平台设置”。此时不会启用计划。
6. 点“仅制作一组预览”，到分发记录检查文案、平台和账号。这一步不上传、不发布；可以取消并释放素材。
7. 确认规则后选择“全自动按官方定时发布”，保存，再点击“启用每日计划”。“先生成草稿，由我确认”模式始终需要逐条确认。

新文件最后修改满 1 分钟才会读取。创建任务会复制素材并核对内容摘要；生成文案期间素材变化会停止。使用记录按文件内容识别，改名或移动已选素材不会再次选用。原素材保留，不自动移动源文件夹。

软件会提前把时间填入官方定时控件，当前准备窗口为发布前 2 小时 15 分钟至 26 小时。Mac 须在准备阶段运行且联网；官方确认接收定时以后，由平台负责到点发表。错过准备窗口不会补发过去的时点。发布失败、账号变化或待验证会暂停相关每日计划，保留记录等待处理。

使用固定文案时，在每组素材所在文件夹放置：

```json
{
  "title": "这一组的标题",
  "content": "已经人工确认的正文，可包含换行。",
  "short_title": "视频号视频短标题"
}
```

短标题可省略；视频号视频填写时须为 6～16 个字符。固定话题在每日规则里设置。同一文件夹多组素材若需不同的手工文案，应分成子文件夹；近期高度重复的文案会停止生成任务。

## 账号画像与识图设置

默认沿用当前 Chrome 账号已有的小红书画像。可在每日分发下方添加每个平台的长说明，包括定位、受众、实际优势、禁写内容和语气；只有点击确认保存的内容才用于后续文案。联网补充先显示建议和来源，不能直接把行业介绍当作本店事实。无关或不可用的搜索结果不会改写画像；可人工补充核实过的资料。

后台“可选 · AI 识图与视频抽帧”支持 OpenAI Chat Completions、OpenAI Responses 和 Gemini 原生协议；有 OpenAI、豆包 / 火山方舟、千问 / 百炼、Gemini 预设，也可填兼容服务地址。豆包填写实际推理接入点或模型 ID。更换服务域名时须重新填对应密钥，避免把旧服务密钥发给新服务。密钥不用发送到聊天里。

千问、Gemini 和豆包的模型名称按自己控制台实际开通的视觉模型填写；千问地址还需匹配地域 / 业务空间，预设兼容地址可修改。API 字段参考 [OpenAI 视觉接口](https://developers.openai.com/api/docs/guides/images-vision)、[千问视觉接口](https://help.aliyun.com/zh/model-studio/vision)、[火山方舟视觉接口](https://docs.volcengine.com/docs/ark/image-understanding?lang=zh) 和 [Gemini 图片理解](https://ai.google.dev/gemini-api/docs/image-understanding)。预设不代表对应账号已开通模型或具有可用额度。

图片会缩小后采样，视频最多均匀抽取 6 帧，视频抽帧依赖已加入安装依赖的 `imageio-ffmpeg`。当前视频识别不含音频，也不能证明未采样画面的内容。未勾选识图时，仅根据账号资料和 `发布说明.txt` 等备注写作；不推断未看到的拍摄细节。AI 输出仍可能出错，正式全自动前应先用预览模式检查自己的素材和提示词。

## 能力与实测边界

| 项目 | 当前情况 |
| --- | --- |
| 图文 / 视频上传、标题 / 正文 / 换行 / 话题 | 三平台接入；原生字段读回核对 |
| 独立声明、位置、合集、活动、图文配乐 | 按账号官方可用控件操作；没有的选项不会伪造 |
| 可见范围、下载权限 | 抖音按实际控件核对；视频号当前网页无发布前私密选项 |
| 官方定时 | 精确到分钟；抖音私密或好友可见不能与定时组合 |
| 自定义封面、@、商品 / 扩展链接等 | 有需在官方页操作的项目，未实现全部自动填写和核对；不能称所有官方功能 1:1 完成 |
| 分发恢复和结果 | SQLite 任务、素材固定、重复提交保护、逐平台结果核实 |
| 长视频 / 超大文件 | 支持上传与等待恢复；本轮真实视频测试为 8 秒，不代表平台标称最大文件已实测 |
| 长期无人值守 | 尚需自己的日更素材持续运行验收，登录 / 审核 / 验证可能需要人工处理 |

截至 **2026-11-19 下午**的真实结果：视频号图文已在官方列表核实作品 ID；视频号定时视频已于 **11 月 19 日 02:33 北京时间**发表，并核实最终作品 ID；小红书视频在“已发布”筛选中核实，且为“仅自己可见”；抖音图文在用户完成短信本人验证后核实已发布，另有一条视频通过软件实际提交，已在官方列表核实作品 ID。视觉模型以软件已有兼容服务做过真实图片与视频识别；四家官方服务没有全部逐家真实调用通过。上述结果验证有限测试作品，不代表每个低频设置、超大文件或长期日更均已验收。

另外完成一批真实文件夹取图、识图配文和三平台分发：同一文案与话题在三个平台最终均核实已发布，小红书为私密测试。完整验收包含登录恢复、话题节点与窄窗口问题修复后继续原任务，未重复发表已成功的平台。

这些测试使用独立数据库，未启动正式运营计划。验收材料保留在开发机 `2026-11-18/full-automation/`。这次未发布 GitHub Release，也未自动升级其他用户的软件。
