# 抖音、视频号与多平台分发

适用本地版本 2026.11.19。发布区根据本机已登录的官方创作页面接入，保留原软件外壳，并增加共用素材、分发选择和逐项核对。

## 现在能做什么

| 能力 | 抖音 | 视频号 |
| --- | --- | --- |
| 图文、视频上传 | 已接入 | 已接入 |
| 标题、正文、换行、真实话题 | 已接入；图文标题 20 字、视频标题 30 字 | 已接入；图文标题 22 字，视频短标题 6～16 字或留空 |
| 图片上限 | 35 张，单张 50MB | 18 张，单张 20MB |
| 视频上限 | 3 小时，64GB | 8 小时，20GB |
| 公开、好友、仅自己可见 | 已接入 | 当前官方网页没有这些可见范围选项；软件不伪造私密发布 |
| 下载保存权限 | 已接入 | 当前网页无对应选项 |
| 立即、定时发布 | 已接入，精确核对到分钟 | 已接入，精确核对到分钟 |
| 位置、合集、活动 | 读取官方可用选项，并按所选值填写 | 读取官方可用选项，并按所选值填写 |
| 图文配乐 | 已接入，包括“不添加音乐” | 已接入，包括清除平台自动配乐 |
| 关联热点 | 已接入 | 当前网页无对应选项 |
| 内容声明 | 已接入 | 已接入；自行拍摄支持日期/地点，转载支持来源 |

选项由当前账号的官方页面提供。输入一个地点简称不代表平台有同名地点：应点击“选择”，搜索后选中完整名称。账号没有合集或活动时，软件不会生成虚构选项。

文案与素材在两个新平台间共用，设置分别保存。视频号视频的短标题留空时，联合工作台使用共用标题；超过官方长度限制会停止，需填写适合的短标题，不会截断。

**图文、视频均支持勾选小红书、抖音、视频号，一次确认分发。** 小红书图文复用原有发布器、账号校验、素材处理、隐私和排期设置。联合分发不会自动重写已经确认的文案或更换话题。新增每日文件夹计划与可选视觉模型，见 [每日多平台分发与 AI 识图](每日多平台分发与AI识图.md)。

## 第一次使用

1. 打开软件，在左上角“创作服务平台”菜单切换抖音或视频号。
2. Chrome 中登录对应创作平台。点击“刷新页面列表”，选择正确账号的页面，再点“连接”。连接记录可在软件重启后恢复，操作前仍会核对页面账号。
3. 选择图文或视频、选择素材，写一次标题、正文、话题。也可以点“从小红书带入素材和文案”。
4. 分别切换平台确认隐私、定时、声明、合集、位置等设置。只填共用文案不会自动把抖音的私密范围变成视频号的私密范围。
5. “填写并逐项核对”会在需要时新建发布页、上传素材、填写内容，并读回官方控件。它停在提交前。也可以手动“新建发布页”→“上传到平台”。
6. 勾选要分发的平台，点击发布。确认窗口列出各平台可见范围和时间。全部所选平台准备并核对通过后，才逐个平台提交。平台之间无法做服务器层面的同时事务：可能有的平台已接收，另一个平台暂时失败。
7. 结果不明时查看顶部“分发记录”和官方作品管理。软件会保留每个平台的结果，不会自动整批重发。“继续尚未提交的平台”会跳过已提交和结果不明的平台。

从本软件的小红书发布页开始，先选图文或视频，定好稿件，再在底栏勾选“同步抖音”“同步视频号”。“发布”会显示目标账号、隐私和时间。“仅填入发布页”会为整批建立只填页任务，待核对通过后可从分发记录确认发布。

| 小红书最终设置 | 抖音 | 视频号 |
| --- | --- | --- |
| 图片及顺序、Logo、水印、视频文件 | 使用同一份最终素材 | 使用同一份最终素材 |
| 标题、正文、话题 | 共用，话题最多 5 个 | 图文共用；视频短标题适用 6～16 字限制 |
| 可见范围 | 对应公开、好友或仅自己可见 | 这两个测试入口只支持公开，确认框单列提醒 |
| 立即或定时 | 同一分钟；非公开与定时冲突会停止 | 同一分钟，须通过官方日历核对 |
| 合集、地点 | 尝试匹配本账号的同名选项 | 尝试匹配本账号的同名选项 |
| AI、虚构、营销、转载声明 | 转换为抖音的声明名称 | 转换为视频号的标注名称，转载时共用小红书填写的媒体名称 |
| 自主拍摄来源 | 没有等同声明 | 沿用拍摄日期，另选视频号官方地区路径 |
| 原创、允许正文复制、小红书活动及 @ 用户 | 不跨账号复制；下载权限、热点、音乐及活动取抖音设置 | 不跨账号复制；音乐、活动等取视频号设置 |
| 营销链接、投票、群聊、路线、自定义封面等 | 需在官方页面操作 | 需在官方页面操作 |

2026-11-19 使用真实账号从小红书入口勾选抖音、视频号，分别提交了图文和视频。两批均在三家作品管理取得作品 ID。小红书、抖音当次选用仅自己可见，视频号使用公开范围。

同日另在官方图文草稿核实了三平台虚构声明，小红书、抖音和视频号的 AI 及营销声明，小红书的来源转载和自主拍摄，视频号的转载来源及拍摄日期与地区。小红书和视频号会分别核对详细信息。小红书活动用“读取官方活动”读取当前账号已经上传素材的发布页，可关联和取消。抖音和视频号都现场选中并清除了非空地点和配乐。抖音、视频号测试账号均未提供可选的非空合集，视频号亦未提供可选活动。没有唯一匹配的目标选项时，分发会停在提交前。

## 定时与上传中的保护

- 当前工作台的定时校验窗口为北京时间 2 小时后、14 天内；这是统一工作台采用的限制，官方实际可选范围仍由官方日历校验。上传完成后、提交前会再次检查。
- 抖音选择定时会将可见范围恢复为公开。因此“定时＋仅自己可见/好友可见”组合会被阻止，不能把私密任务悄悄改成公开任务。
- 视频号图文可能自动添加音乐或位置，软件会显式处理“不添加音乐”“不显示位置”。
- 图片出现不等于上传完成：会等待处理结束和素材地址稳定，再保存上传核验记录。软件重启后可继续核验同一份已上传素材。
- 修改文案或设置会使旧确认失效。提交前还会检查账号、素材、内容、真实话题和发布设置。
- 每个提交凭证只能使用一次。点击发布前先记录尝试；结果不明、请求中断或服务重启后不会自行重复点击。
- 出现登录失效、验证码、频率限制或无法匹配的控件时停止，保留具体错误供处理。

## 本次尚未覆盖

- 官方页面的高级封面编辑、@ 用户、商品/小程序等链接、商业合作等少用模块，没有全部做成本地自动填写控件。带有“在官方页”提示的入口需要人工操作，不能视为自动填写和核验已完成。包含未支持设置的内容应在官方页人工复核后处理。
- 界面保留原软件导航和分发工具，因此不能称为官方页面的逐像素、全功能复制。不同账号权限和后续页面改版也可能改变选项。
- 小红书视频已接入联合分发。每日目录计划另见《每日多平台分发与AI识图》。
- 官方“跳转到作品管理”只表示提交环节有反馈，不等于审核通过或公开展示成功。发布后的最终状态应在各平台作品管理确认。

## 你需要准备什么

只需本机 Chrome 的登录状态、发布素材、目标账号和平台设置。首次登录或登录失效时扫码即可，不需要提供密码，也不需要导出 Cookie。运行上传/填写时保持 Mac 和 Chrome 可用；已被官方接收的定时任务按平台时间执行。

AI 文案和高级封面处理可在后续复用现有软件能力；本次新增模块优先保证已填写内容与官方表单一致。平台检测机制无法承诺永久规避，当前实现不绕过验证码或安全验证。

## 开源复用

参考并适配了 MIT 项目 [千帆云递](https://github.com/laoshalab/social-auto-upload-web-ui-pro) 的日历和发布控件逻辑，保留许可证与来源说明于 `app/vendor/platform-adapters/`；同时评估了 [social-auto-upload](https://github.com/dreammis/social-auto-upload)。现有软件的接口、Chrome 连接、数据和小红书能力继续复用。当前视频号的 Shadow DOM、图文发布、真实话题、选项清空和提交核验是在此基础上补齐的。
